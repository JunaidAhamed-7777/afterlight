# Pre-test analysis correction

The first development-selection command stopped during raw evidence verification,
before model fitting or selection-output creation. Its original watcher journal
and traceback are retained. The collector had correctly used the complete frozen
analytical estimator configuration. The study verifier instead reconstructed the
legacy pilot defaults from the scalar objective weight: integer `1` serialized
differently from the frozen configuration's floating-point `1.0`.

The correction consumes the complete original estimator configuration and version
and requires its exact original canonical SHA-256. It does not normalize either
configuration or evidence, accept an alternative hash, or rewrite collected rows.
All original metric, decision, timing, lifecycle, signal, source, release and
collection-inventory checks remain in effect. The simulation, candidate leads,
features, objective, split assignments, model specification and held-out collection
code remain pinned to the original scientific checkout.

`scripts/run_analysis_amendment.py freeze` creates a separate, fresh source bundle
and descriptor before fitting or test release. It binds the original study,
protocol, simulation-source inventory, exact estimator, failed attempt, revised
analysis sources and reviewable patch. Source execution compiles the verified raw
bytes under the separate analysis module names; cached bytecode cannot substitute
for those bytes. The original checkout's modules and source guards are unchanged.

The frozen entry point supports an explicit selection, read-only selection review,
report creation and report verification. Every successful command rechecks the
same descriptor identity. Selection and report embed the amendment binding in
their logical hashes. The unchanged original test-release process then binds the
complete selection file, including that amendment. Report verification checks
this binding before opening released test outcomes.

The publication exporter requires the explicit descriptor for an amended report.
It copies all seven original amendment companions and their byte hashes into the
public proof pack. The public verifier checks their identities and chronological
bindings without executing downloaded analysis code. Neither the failed journal
nor provenance metadata independently proves human nonaccess; the retained stack
and absent failed selection directory identify where the original command stopped.

The synthetic regressions in `tests/acceptance/test_analysis_amendment.py`
reproduce the original integer/float failure, verify a complete nondefault frozen
configuration, retain rejection of altered raw evidence, reject numeric-equal but
hash-different estimator metadata, ignore poisoned cached bytecode, protect inputs
before writes, reject a wrong amendment before test evidence, and reject an
internally resealed amendment during a command. They perform no simulation,
collection or model fitting.

After the original collection finished, canonical main received the same
complete-estimator study binding as a separately reviewed future-study fix.
Legacy pilot verification remains compatible. That new main-source identity
does not replace the original simulation checkout, frozen analysis bundle,
selection, model, report or their recorded hashes.
